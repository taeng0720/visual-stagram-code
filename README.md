# Visual Stagram Code

VS Code처럼 보이는 인스타그램 DM 앱. 대화가 파이썬, C#, C++ 같은 코드처럼 보입니다.

## 1. 로그인

탭 줄 오른쪽 끝의 미리보기 아이콘을 누르면 인스타그램 로그인 화면이 나옵니다.
로그인이 끝나면 자동으로 이 화면으로 돌아오고, 다음부터는 로그인된 채로 열립니다.
비밀번호는 instagram.com 페이지에 직접 입력되며 이 앱은 저장하지 않습니다.

## 2. 대화 열기

왼쪽 EXPLORER는 진짜 개발 프로젝트처럼 보입니다. 대화방은 인스타 이름을 영어로 바꾼 파일 이름으로 섞여 있고 (`김민수` → `kim_minsu.py`, `배고파` → `hungry.py`, C#이면 `KimMinsu.cs`),
나머지 파일은 열어도 그냥 코드만 보이는 가짜 파일입니다. 이 설명서는 `README.md`를 누르면 다시 볼 수 있습니다.

- `Ctrl+P` (맥은 `Cmd+P`) : 빠른 열기. 파일 이름뿐 아니라 상대의 인스타 이름·아이디로도 찾을 수 있습니다.
  앞글자(`kim`), 단어 머리글자(`km` → `kim_minsu.py`), 초성(`ㄱㅁㅅ` → 김민수), 영어 발음(`minsu`), 띄어 쓴 여러 단어 모두 됩니다. 명령 팔레트·사람 찾기·OUTLINE·확장 검색도 같은 방식입니다
- 새 메시지가 온 대화 파일은 git 수정 표시처럼 노란 이름과 `M` 이 붙습니다 (접힌 폴더에는 `●`)
- `Esc` : 대화를 보다가 누르면 바로 가짜 코드 파일로 바뀝니다
- `Ctrl+B` : 사이드바 접기/펴기
- 대화 파일은 인스타처럼 최근 대화가 위에 옵니다. `File` > Chat Files 에서 이름순 정렬, 또는 `router.py` 같은 일반 모듈 이름으로 바꿀 수 있습니다
- 영어로 깔끔하게 바뀌지 않는 이름(뜻을 알 수 없는 단어, 이모지, 자음만 있는 이름 등)은 인스타 아이디로 나옵니다. 팔로워·팔로잉이면 바로, 아니면 그 대화를 한 번 열었을 때 바뀝니다. 단체방은 열었을 때 참여자 두 명의 아이디로 나옵니다
- `F2` 나 새 파일에 한글로 이름을 쓰면 바로 영어로 바뀝니다 (`민수 친구` → `minsu_friend`)
- 파일 아이콘은 VS Code 기본 아이콘 테마(Seti)와 같습니다. 이 컴퓨터에 VS Code가 깔려 있으면 작업표시줄과 창 왼쪽 위 로고도 VS Code 아이콘으로 바뀝니다
- 대화를 불러오는 동안에는 편집기 위에 파란 진행 막대가 흐르고, 아래 상태 줄의 동기화 아이콘이 돕니다

### 왼쪽 탭과 아래 패널

- 검색 (`Ctrl+Shift+F`) : 가짜 파일 내용, 대화 파일 이름(실제 이름 포함), 열려 있는 대화의 메시지를 찾습니다
- 소스 제어 (`Ctrl+Shift+G`) : 새 메시지가 온 대화가 Changes 에 뜨고 아이콘에 숫자가 붙습니다. Commit 을 누르면 이 앱에서만 읽음 처리됩니다 (인스타에는 영향 없음)
- 실행 및 디버그 (`Ctrl+Shift+D`, `F5`) : 가짜 실행 로그가 Debug Console 에 뜹니다. launch.json 도 만들 수 있습니다
- 확장 (`Ctrl+Shift+X`) : 프로젝트 언어에 맞는 설치된 확장 목록. 누르면 상세 화면이 열립니다
- 톱니바퀴 > Settings (`Ctrl+,`) : 위장 코드 양, 파일 이름 방식, 정렬, 템플릿, 프로젝트 이름. Keyboard Shortcuts 에 단축키 정리
- `Ctrl+Shift+P` : 명령 팔레트. `Ctrl+P` 에서 `?` 를 치면 `@`(사람 찾기), `>`(명령) 같은 사용법이 나옵니다
- ``Ctrl+` `` 또는 `Ctrl+J` : 아래 패널. 터미널에서 `ls`, `cd`, `cat`, `git status`, `git log`, 테스트 명령 등이 됩니다
- 위쪽 메뉴(File, Edit, View, Go, Run, Terminal, Help)도 모두 열립니다

### 탭과 단축키

- 파일과 대화가 위쪽에 탭으로 쌓입니다. 탭은 다음 실행 때도 그대로 남습니다
- `Ctrl+Tab` : 최근 탭 목록. `Ctrl` 을 누른 채 `Tab` 으로 고르고 손을 떼면 이동
- `Ctrl+PageDown` / `Ctrl+PageUp` : 다음/이전 탭, `Alt+1`~`Alt+9` : N번째 탭
- `Ctrl+W` : 탭 닫기 (다 닫으면 빈 편집기 화면), `Ctrl+Shift+T` : 닫은 탭 다시 열기
- `Alt+←` / `Alt+→`, 제목 줄 화살표 : 이전/다음 편집 위치 (인스타 실제 화면에서는 인스타 뒤로/앞으로)
- `Ctrl+G` : 줄 번호로 이동

### 가짜 코드 직접 고치기

- 대화가 아닌 코드 파일은 열어서 바로 타이핑해 고칠 수 있습니다. 이 컴퓨터에 자동 저장되고 `Ctrl+S` 도 됩니다
- 이미지·사운드·모델 같은 파일은 VS Code처럼 "바이너리라서 표시하지 않음" 안내가 나옵니다

### 알림

- 새 메시지가 오면 작업표시줄 아이콘에 숫자 배지가 붙고, 창이 뒤에 있으면 아이콘이 깜빡입니다. 탐색기·소스 제어 아이콘 배지, 탭의 `●`, 파일의 `M` 도 함께 바뀝니다
- 앱 안에서는 오른쪽 아래에 "Incoming changes in 파일이름" 알림이 뜹니다. 상태 줄 종을 누르면 지금 새로 온 대화를 다시 볼 수 있습니다
- 읽음 여부는 인스타그램의 읽음 표시를 따릅니다. 폰에서 이미 읽은 대화나, 앱을 껐다 켜기 전에 이미 알림을 받은 메시지는 다시 알리지 않습니다

### 새 DM 열기

- **탐색기 아래 `OUTLINE` 을 누르면 팔로워·팔로잉 목록이 펼쳐집니다.** 위 칸에 아이디나 이름(한글·영어 모두)을 쓰면 걸러지고, 사람을 누르면 DM이 열립니다

- `Ctrl+Shift+O` (맥은 `Cmd+Shift+O`), 또는 `Ctrl+P` 에서 `@` 를 먼저 치면 팔로워·팔로잉 목록에서 사람을 찾습니다. 아이디나 이름으로 검색하고 Enter 를 누르면 그 사람과의 DM이 열립니다
- 단체방에서 이름 주석이나 메시지 줄을 우클릭 > `Go to Definition` 하면 그 사람과의 DM이 열립니다. `Go to References` 는 그 사람이 보낸 줄을 표시하고, `Copy Symbol Name` 은 `@아이디` 를 복사합니다
- 대화 입력 줄에서 `@` 를 치면 자동완성처럼 사람 목록이 뜹니다 (단체방 참여자 먼저). 화살표로 고르고 `Enter`/`Tab`
- 단체방에서 어떤 사람의 메시지 줄을 `Ctrl+클릭` (맥은 `Cmd+클릭`) 하면 그 사람과의 1:1 DM이 열립니다. `Ctrl` 을 누르고 있으면 누를 수 있는 줄에 밑줄이 생깁니다
- 프로필에 메시지 버튼이 없어서 열지 못하면 15초 뒤 실제 인스타 화면으로 바뀝니다. 거기서 직접 메시지를 누르면 다시 코드 화면으로 돌아옵니다

### 프로젝트 템플릿과 언어

메뉴의 `File` > Open Template 에서 프로젝트 모양을 통째로 바꿉니다 (맥은 EXPLORER 옆 `...` 버튼).
Python(FastAPI, Django), Node.js, Spring Boot, Go, ASP.NET Core, React, Next.js, Vue, Unity, Unreal, Flutter, Android, iOS, C++(CMake), C(임베디드), Rust, Laravel, Rails, LÖVE 가 있습니다.

- 대화 파일의 확장자가 곧 언어입니다. `.cs` 면 `Console.WriteLine("안녕");`, `.cpp` 면 `std::cout << "안녕" << std::endl;` 처럼 보입니다
- 지원 언어 : Python, C, C++, C#, Java, JavaScript, TypeScript, Go, Rust, Kotlin, Swift, Dart, PHP, Ruby, Lua
- 확장자만 바꿔도(`F2`) 그 대화만 다른 언어로 보입니다
- 템플릿을 바꾸면 직접 만든 파일·폴더는 새 템플릿 것으로 바뀌고, 이름을 직접 바꾼 대화 파일은 이름을 유지한 채 새 언어 확장자로 옮겨집니다

### 탐색기 꾸미기

이름과 폴더 구조는 이 컴퓨터에만 저장됩니다. 인스타그램의 방 이름은 바뀌지 않습니다.

- 이름 바꾸기 : 파일/폴더를 고르고 `F2`, 또는 오른쪽 클릭 > Rename
- 새 파일·새 폴더 : EXPLORER 제목 줄에 마우스를 올리면 나오는 버튼, 또는 오른쪽 클릭. `a/b/c.py` 처럼 쓰면 폴더까지 만들어집니다
- 옮기기 : 파일이나 폴더를 다른 폴더로 끌어다 놓기 (빈 곳에 놓으면 맨 위로)
- 지우기 : `Delete`. 대화 파일과 README.md는 지워지지 않고, 폴더를 지우면 안에 있던 대화 파일은 맨 위로 나옵니다
- 프로젝트 이름 : 맨 위 `BACKEND-SERVICE` 를 더블클릭. 창 제목에도 그대로 쓰입니다
- 새로 생긴 대화방은 템플릿의 기본 폴더(Python은 `src/handlers`, Unity는 `Assets/Scripts/Systems` 등)에 들어갑니다

## 3. 읽기

- `print("안녕")` : 받은 메시지. 줄 번호 옆에 파란 막대가 붙습니다
- `reply = input("안녕")` : 내가 보낸 메시지. 변수 이름은 매번 다르고, 초록 막대가 붙습니다
- 그 사이의 함수, 반복문 같은 코드는 진짜처럼 보이게 섞어 넣은 위장 코드입니다
- `# 오후 9:03` : 시간, 읽음 표시, 보낸 사람 이름
- `print(open("photo.jpg"))` : 사진과 GIF. 마우스를 올리면 미리보기가 뜹니다
- 맨 위에서 더 위로 스크롤하면 이전 메시지를 불러옵니다

## 4. 보내기

마지막의 `reply = input()` 같은 줄이 입력 줄입니다. 괄호 안에 쓰면 따옴표가 자동으로 붙고, Enter를 누르면 전송됩니다.

## 5. 사진 보내기

- 복사한 이미지를 마지막 줄에 붙여넣기 (`Cmd+V`, Windows는 `Ctrl+V`)
- 파일을 에디터 위로 끌어다 놓기
- `Cmd+O` (Windows는 `Ctrl+O`) 로 파일 고르기

`# 1 attachment(s) ready, Enter sends` 줄이 뜨면 Enter로 보냅니다.

## 6. 위장 코드 양 조절

아래 상태 줄의 `Spaces: 2` 를 누를 때마다 `0`, `2`, `4`, `8` 로 바뀝니다.
숫자가 클수록 메시지 사이에 위장 코드가 많이 섞이고, `0` 이면 메시지 줄만 보입니다.

## 7. 쓰던 VS Code에서 쓰기 (확장)

이 앱을 설치하고 한 번 로그인해 두면, 진짜 VS Code 안에서도 DM을 볼 수 있습니다.

- VS Code의 확장 보기에서 `Visual Stagram Code` 를 검색해 설치합니다
- 검색에 나오지 않는 에디터(Cursor 등)는 `visual-stagram-code.vsix` 를 받아 확장 보기 > `...` > "VSIX에서 설치" 로 설치합니다
- 탐색기 아래 `DIRECT` 목록에서 `이름.py` 를 누르면 대화가 열립니다
- 대화 파일에서 Enter를 누르면 입력창이 뜨고, 쓰고 Enter를 누르면 전송됩니다
- 확장은 이 앱을 창 없이 뒤에서 실행해 씁니다. 따로 켜 둘 필요는 없습니다

## 그 밖에

- 미리보기 아이콘 : 실제 인스타그램 화면과 코드 화면을 전환합니다.
  GIF·스티커 검색, 통화, 메시지 삭제처럼 코드 화면에 없는 기능은 실제 화면에서 하세요
- 왼쪽 맨 위 탐색기 아이콘 : 사이드바를 접고 폅니다
- 제목 줄의 화살표 : 인스타그램 화면의 뒤로/앞으로

## 설치

- macOS : `Visual-Stagram-Code-mac-arm64.dmg` 를 열어 Applications로 끌어다 놓습니다 (Apple Silicon 맥).
  처음 열 때 막히면 시스템 설정 > 개인정보 보호 및 보안 > "그래도 열기"
- Windows : `Visual-Stagram-Code-Setup.exe` 를 실행합니다. 시작 메뉴 검색에서 `vsc`, `inst`, `insta` 로도 찾을 수 있습니다 (`VSC Instagram DM` 바로가기).
  "Windows의 PC 보호" 창이 뜨면 추가 정보 > 실행

## 개발

- `src/` 앱 코드, `build/` 설치 파일 아이콘·설정, `docs/` 소개 페이지, `vscode-extension/` VS Code 확장
- `npm install` 후 `npm start` : 실행
- `npm test` : 자체 점검
- `npm run dist` : 설치 파일 만들기 (`dist/` 에 macOS `.dmg`, Windows `.exe`). Windows 에서는 `npm run dist:win`
- `cd vscode-extension && npm run package` : VS Code 확장 만들기 (`dist/visual-stagram-code.vsix`)
